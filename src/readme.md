# Sistema SVI (MVP)

Aplicación web simple para alta y gestión de productos con:

- Formulario de registro de producto.
- Tabla de productos con eliminación individual.
- Métricas en tiempo real: total de productos, stock y valor total de inventario.
- Persistencia local con `localStorage`.

## Cómo ejecutar

Desde la raíz del repositorio:

```bash
python3 -m http.server 4173
```

Luego abre:

- `http://localhost:4173/src/index.html`
